# 13 締切前オッズの記録(全レース・非公開)

- 作成: 2026-11-07(PM)。利用者の決定。目標(00 冒頭)の柱①。
- 目的: 「買う時点で見えていたオッズ」を全レースで記録し、期待値の検証(確定オッズでは後知恵になる。03 6章・07 7章)と、期待値で選ぶ仮想の購入者(11 8章の期待値さん)に使う。
- **記録したオッズは公開しない**(07 1章。公開JSON・リポジトリ・ログに数値を出さない)。

## 1. 取得

| 項目 | 内容 |
|---|---|
| 対象 | 全レース(中止・順延を除く) |
| ページ | **`oddstf`(単勝・複勝)と `odds2tf`(2連単・2連複)の2ページ**を1回ずつ |
| 3連単(`odds3t`) | **未決(利用者の判断待ち。U17)**。設定(環境変数 `ODDS_RECORD_PAGES`、既定 `oddstf,odds2tf`)に `odds3t` を足すだけで取れる作りにする |
| タイミング | **締切の5分前**(Cron の5分ごとの起動で、締切まで 7〜3分のレースを1回だけ。取り直しはしない) |
| 取得元 | **Cloudflare Worker**。Cron Trigger は無料枠の上限(5つ)に達しているので、**既存の beforeinfo Worker(`*/5`)に同居させる**(同じ起動の中で、直前情報 → オッズの順に処理) |
| 間隔 | 1件ずつ順番に1.5秒以上(直前情報と合わせて、同じ起動の中で順番に) |
| 1日の上限 | **300ページ**(直前情報の上限 300 とは別に数える。環境変数 `ODDS_DAILY_LIMIT`) |
| 停止 | 403・429、または3回続けての失敗で、**その日のオッズの記録を止める**(`odds/YYYYMMDD/_stopped.json`)。直前情報の停止とは別の印にする。どちらかが 403・429 を受けたら両方止める(同じ相手のため) |
| 1日の量 | 約150レース × 2ページ ≒ **約300ページ**(13場の日。24場の日は上限で打ち切り。打ち切ったレースは `skipped_limit` と記録) |
| CPU時間 | 1回の起動で解析するのは、直前情報と合わせて最大3ページ(12 2.2)。足りないときは、オッズは締切に近いレースを優先し、残りは次の起動へ(窓 7〜3分前に収まる範囲で) |

- 公式サイトへのアクセスの合計(オッズ中継 300 + 直前情報 300 + オッズの記録 300)は、上限いっぱいでも1日900ページ。いずれも逐次・1.5秒以上・拒否されたら停止で、07 1章の方針(大量のアクセスにしない)の範囲とする。

## 2. 保存

- **R2 の非公開領域** `br-yoso-data/odds/YYYYMMDD/SS-RR.json`(公開しない。公開物 `docs/` には出さない)。
- 形式は 07 2.6 の解析結果と同じ(`odds` の入れ子の dict、`odds_time_label`、`is_final_odds`)に、次を加える:
  - `fetched_at`(取得時刻)、`minutes_before_close`、`closed_at`、`pages`(ページごとの結果)、`status`(`ok` / `partial` / `failed` / `skipped_limit`)。
  - **取得の時刻をオッズの時点として記録する**(公式の「オッズ更新時間 HH:MM」の表記も `odds_time_label` に残す)。
- 容量: 1レース約3KB × 150 ≒ 0.5MB/日、年 約180MB(R2 10GB の見積もり 10 2.3 に追加)。

## 3. 解析

- `src/collect/official_odds.py`(Python)と、odds-proxy の `parse.mjs`(JS)と**同じ解析**を使う。beforeinfo Worker からは odds-proxy の `parse.mjs` を共有する(コピーせず、同じファイルを参照する作りにできなければ、同じ内容であることをテストで確かめる)。
- 共通の fixture: `tests/fixtures/official_odds/`(07 9.5)。`0.0` は null、欠場艇の組合せは null(07 2.2)。

## 4. 取り込み(Actions の前日確定ジョブ)

- 前日確定ジョブ(1:12)で、R2 の `odds/YYYYMMDD/` を読み、interim の **締切前オッズの表** に入れる(F)。
  - `data/interim/odds_pre/YYYY-MM.parquet`(**公開しない**。git管理外)。列: `race_id, bet_type, combination, odds, odds_lower, odds_upper, fetched_at, minutes_before_close, source`(`source` = `worker_record`。PC のループ(07 2章)や中継で取ったものと区別する)。
  - 確定オッズの表(`odds`。turnmark)とは別の表にする。
- 使い道:
  - 期待値の検証(M): 締切前オッズで計算した期待値と、確定の払戻での実際の回収率(07 7章の M-7・M-8)。
  - 仮想の購入者「期待値さん」(M): **2〜4週分たまってから**追加する(11 8章)。
