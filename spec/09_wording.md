## 1. 用語説明「?」(`help.*`)

| キー | 見出し | 文言 |
|---|---|---|
| `help.probability` | 確率 | モデルが計算した、その着順になる見込みです。過去のデータから作った推定で、外れることもよくあります。 |
| `help.calibration` | 較正(かくせい) | 「予測の確率」と「実際に当たった割合」がどれだけ一致しているかです。グラフの点が斜めの線に近いほど、確率をそのまま信じやすいモデルです。線より下にあるときは、モデルが強気すぎます。 |
| `help.required_odds` | 必要オッズ | 期待値がちょうど1.0(損も得もしない)になるオッズです。1 ÷ 確率 で計算します。実際のオッズがこれより低ければ、長く買い続けると損になる見込みです。 |
| `help.expected_value` | 期待値 | 確率 × オッズ です。1.0より大きいと長い目で見て得、小さいと損の見込みです。確率の推定がずれていると、期待値もずれます。締切前のオッズは締切までに変わります。 |
| `help.ev_rank` | 期待値ランク | 期待値を A(1.2以上)・B(1.0〜1.2)・C(0.8〜1.0)・D(0.8未満)の4段階にしたものです。 |
| `help.confidence_interval` | 信頼区間(95%) | 数字のぶれの幅です。件数が少ないほど幅が広くなります。回収率の区間が100%をまたいでいるときは、「プラスともマイナスとも言えない」という意味です。 |
| `help.sample_size` | 件数 | 集計に使ったレースや買い目の数です。少ない件数の成績は偶然の影響が大きいため、200レース未満の数字は薄く表示しています。 |
| `help.roi` | 回収率 | 払戻の合計 ÷ 購入額の合計 です。100%を超えるとプラスです。ボートレースは控除率があるため、平均的には75%前後になります。 |
| `help.hit_rate` | 的中率 | 買ったレースのうち、1点以上当たったレースの割合です。的中率が高くても、回収率が高いとは限りません。 |
| `help.backtest_vs_live` | 検証と実運用 | 「検証」は過去のデータで、後から計算した成績です。買い方の条件を選んだ期間を含むため、実際より良く見えがちです(後知恵)。「実運用」は、その日の朝に確定した予想で記録した成績です。 |
| `help.prediction_version` | 予想の版 | 「前日版」は出走表だけで作った予想、「直前版」は展示タイムなどの直前情報も使った予想です。どちらも一度確定したら書き換えません。 |
| `help.reasons` | 確率の根拠 | その艇の確率を上げた・下げた要因のうち、影響が大きかったもの3つです。モデルの計算の内訳で、因果関係を示すものではありません。 |
| `help.combined_odds` | 合成オッズ | 複数の買い目を同じ金額で買ったとき、全体として何倍になるかの目安です。 |
| `help.torigami` | トリガミ | 当たっても、払戻が購入額の合計より少なく、損になることです。 |
| `help.drawdown` | 最大ドローダウン | 収支が一番良かった時点から、一番落ち込んだ時点までの差です。どれだけ負けが続く可能性があるかの目安になります。 |
| `help.losing_streak` | 最大連敗 | 続けて外れたレースの数の最大値です。 |
| `help.confidence_label` | 堅さ(堅・中・荒) | 本命の1着確率で分けた目安です。堅 50%以上、中 35〜50%、荒 35%未満。 |
| `help.baseline` | 基準の買い方 | 「1号艇の単勝を買い続ける」など、モデルを使わない単純な買い方です。モデルの成績がこれより良いかを比べるために表示しています。 |
| `help.allocation` | 配分のしかた | 予算を買い目にどう分けるかの選び方です。「均等」「上位厚め」「確率に比例」は、過去のデータではどれも回収率が約78%で、ほとんど差がありませんでした(2026年9〜10月)。配分を変えても、長い目で見た損得は大きくは変わりません。損の額は賭け金に比例して大きくなるので、予算は無理のない額にしてください。 |
| `help.allocation_ev` | 期待値に比例 | 期待値が1より大きい買い目ほど多く、1未満の買い目には0円を割り当てます。1点に予算の40%より多くは割り当てません。オッズは締切まで変わり、確率の推定にも誤差があるため、期待値は目安です。期待値が高く見えても、当たるとは限りません。 |
| `help.allocation_payout` | 払戻をそろえる | どの買い目が当たっても、払戻がほぼ同じになるように分けます。オッズが低い買い目ほど多くなります。オッズは締切まで変わるため、実際の払戻はずれます。 |
| `help.skip` | 見送り | 設定した条件(堅さ・確率・期待値)に合う買い目が無いレースです。 |
